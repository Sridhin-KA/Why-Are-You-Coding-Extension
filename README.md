# 😂 Why Are You Coding?

A completely unnecessary VS Code extension that judges your code so you don't have to.

## Features

### 😂 Roast Me

Click **😂 Roast Me** in the VS Code status bar and receive a random developer roast.

### 🔥 Roast This Code

Select some code, right-click, and choose:

**🔥 Roast This Code**

The extension checks your code for some common patterns and gives you a roast.

### 🎚️ Roast Levels

Choose your preferred level of pain:

- 😇 Friendly
- 😏 Sarcastic
- 🔥 Brutal
- 💀 Destroy Me

Your selected roast level is remembered.

## Privacy

Why Are You Coding does not require an API key, external server, or internet connection.

All roasting happens locally inside VS Code.

## Requirements

VS Code 1.133.0 or newer.

## Installation

Search for **Why Are You Coding** in the VS Code Extensions Marketplace.
